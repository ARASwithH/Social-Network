# 🧑‍🤝‍🧑 Social Network

A simple social network web application built using Django. Users can register, log in, create posts, like/unlike others' posts, follow/unfollow users, and view a personalized feed.

## 🚀 Features

- User authentication (register, login, logout)
- Create, edit, and delete posts
- Like and unlike posts
- Follow and unfollow users
- View posts from followed users
- Pagination for posts

## 🛠️ Tech Stack

- **Backend:** Django, SQLite (default)
- **Frontend:** HTML, CSS, Bootstrap
- **Others:** Django Authentication, CSRF protection, Django Admin
